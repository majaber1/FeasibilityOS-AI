# Product readiness

Date: 2026-09-08  
Baseline SHA: `52f21454298254fa9fe299b24372b823bf2566e0`

Saudi Business is a modular monolith: one account and organization, shared Business/Project context, independent tools.

## What is commercially demonstrable

- Independent entry for Feasibility, Financial Analysis, Proposal, Funding, Qualification, Opportunities, Franchise, Reports.
- Optional explicit linking (import preview shows source record, fields, last sync).
- Entitlement model with demo-all-enabled provider. No fake checkout.
- Bilingual AR/EN UI with RTL.
- PostgreSQL-backed persistence for studies, proposals, financial analyses, notifications, analytics events.

## What is not claimed

- Auctions marketplace
- Live government data sync
- Real payment processing
- Complete LangGraph/Groq V2 AI workspace (not in this repository on the baseline)
