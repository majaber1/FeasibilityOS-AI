# Demo script

1. Open `/` — from idea to investment-ready, tools remain independent.
2. Register, land in projects, then open `/dashboard` and pick “What do you want to accomplish today?”
3. `/tools/feasibility/new` — standalone study or link an existing business. Complete the workspace and compute.
4. `/tools/financial` — run a standalone analysis; optionally import feasibility assumptions; save the analysis.
5. `/tools/proposal` — start from scratch; optionally import from a feasibility study; export PDF/DOCX.
6. `/tools/funding` — match without requiring feasibility. Show source URL and “not a guarantee”.
7. `/tools/qualification` — readiness score and Multazim handoff, not a GRC clone.
8. `/tools/reports` — export a study report; compose an investor package from selected sources only.
9. `/tools/auctions` — state clearly that auctions are not in the current product.
